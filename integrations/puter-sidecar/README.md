# DEBiLGI Puter browser bridge

Локальный брокер фоновых структурных консультаций. Он не генерирует сообщения Discord:
готовые ответы запрещены контрактом и отбрасываются валидаторами.

```powershell
npm install
$env:PUTER_SIDECAR_SECRET='та же локальная строка, что в .env бота'
npm start
```

Затем откройте `http://127.0.0.1:43127/bridge`, нажмите «Запустить мост» и оставьте вкладку
открытой. Браузер хранит сессию Puter, sidecar — очередь заданий, а DEBiLGI — проверенные
долговременные уроки. Инструкция для Puter находится в `semantic-instruction.txt` и
добавляется к каждому отдельному запросу, поэтому состояние и личность сессии не важны.

Проверка состояния:

```powershell
Invoke-RestMethod http://127.0.0.1:43127/health
```

`active: true` означает, что вкладка авторизована и продолжает опрашивать очередь.
